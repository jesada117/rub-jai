# Rub-Jai (Android)

1. สมัคร GitHub (ฟรี) แล้วสร้าง repository ใหม่
2. อัพโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ .github) ขึ้น repository
3. เปิดแท็บ Actions -> Build APK -> รอประมาณ 5-8 นาที
4. เปิดงานที่สำเร็จ -> ดาวน์โหลด rub-jai-apk -> แตก zip จะได้ app-debug.apk
5. ส่งเข้ามือถือแล้วกดติดตั้ง (อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก")

แก้โค้ดแอพได้ที่ www/index.html

## ใส่โลโก้และชื่อ
- ชื่อแอพ: แก้ใน capacitor.config.json (appName) ตอนนี้คือ Rub-Jai
- โลโก้: วางไฟล์ logo.png (อย่างน้อย 1024x1024) ในโฟลเดอร์ assets/ ระบบจะสร้างไอคอนและหน้าเปิดแอพให้ตอน build
